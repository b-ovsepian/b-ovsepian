### About

I'm a senior front-end developer at [AWERTI](https://awerti.com/), a livestreaming analytics company in Kyiv. Day to day that means turning large viewership datasets — millions of hours of watch time across Twitch, YouTube, Kick, TikTok and the Chinese platforms — into dashboards, comparison views and report exports that people actually enjoy using.

I like the parts of the job that sit between disciplines: agreeing on an API contract with the back-end, chasing a Core Web Vitals regression, QA-ing on a real iOS WebKit engine instead of trusting Chrome's emulator, or building small tools that make day-to-day work faster.
